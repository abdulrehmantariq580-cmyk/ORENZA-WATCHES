# ORENZA - Luxury Timepieces Shopify Theme

A bespoke, modern Online Store 2.0 luxury watch store Shopify theme tailored for **ORENZA**.

## Features
- **Auto-scrolling Announcement Bar & Promo Tickers**
- **Custom Header with Emblem & Luxury Typography**
- **Mobile Interactive Sliding Drawer Menu**
- **Hero Slider with smooth touch and autoplay transitions**
- **Curated Watch Brands Circular Showcase**
- **Featured Products Grid (4 on Desktop, 2 on Mobile)**
- **Dual Promo Image Banners**
- **Trust Badges Strip (Nationwide Delivery, 100% Authentic, 24/7 Support, Secure COD/Online Payments)**
- **Luxury Heritage About Us Section**
- **Integrated Contact Form, Newsletter & Complete Store Footer**
